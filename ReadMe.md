# JPMorgan Chase & Co. - Midas Core Simulation Project

This project is part of the **JPMorgan Chase & Co. Software Engineering Virtual Experience** on [Forage](https://www.theforage.com/).  
It simulates a real-world backend engineering task using **Java**, **Spring Boot**, and **Kafka**.

## 🛠️ Project Objective

Build the **Midas Core** system – a core financial transaction handler that:
- Receives financial transactions from Kafka
- Validates and stores them in an H2 database
- Communicates with a REST API to incentivize users

## 📦 Technologies Used
- Java 17  
- Spring Boot  
- Apache Kafka  
- H2 Database  
- REST API  
- JUnit for testing
